# audit

Read-only analysis scripts used to diff the lupus backend against the upstream
Lupus implementation. They are not part of any workspace and are never
built or run by `npm run build` / `npm test`.

Run them from the **project root** (every path in them is root-relative):

```bash
node audit/extract-lupus.js
node audit/extract-sdk-calls.js
node audit/map-sdk-http.js
node audit/diff-routes.js
node audit/split-domains.js
node audit/patch-tests.js
```

`dbg-auth.ts` and `smoke-dashboard.ts` boot the backend on an ephemeral port and
write to the configured database, so run them only when you intend to:

```bash
npx tsx audit/smoke-dashboard.ts
```

## Upstream clone

`extract-sdk-calls.js` and `map-sdk-http.js` parse the upstream checkout, which is
**not part of this project**. It stays behind in the old monorepo and must be
pointed at with `LUPUS_UPSTREAM_ROOT` (the directory holding `packages/`):

```bash
LUPUS_UPSTREAM_ROOT=C:/Users/ndhba/Documents/lupus node audit/extract-sdk-calls.js
```

The same value is documented in the project `.env.template`. Both scripts exit
with a clear message if the variable is unset.

## Generated artifacts

These `.txt` files are outputs, regenerated by the scripts above:

- `lupus-routes.txt` — every `router.*` / `app.*` route found under `server/src` (`extract-lupus.js`)
- `dashboard-sdk-calls.txt` — `sdk.admin.*` / `sdk.auth.*` calls used by the upstream dashboard (`extract-sdk-calls.js`)
- `dashboard-http-map.txt` — those calls resolved to HTTP method + path (`map-sdk-http.js`)
- `route-diff-report.txt`, `missing-routes.txt` — upstream vs lupus route diff (`diff-routes.js`)
- `domain-*.txt` — the dashboard's missing routes bucketed by domain (`split-domains.js`)

`upstream-routes.txt` is an input snapshot, not produced by anything in this
directory; refresh it from the upstream clone if the upstream route surface moves.
